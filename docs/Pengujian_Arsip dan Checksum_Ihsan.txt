Pembuatan Arsip Backup (.tar.gz)

Penanggung jawab: Ihsan Fauzan Adziman  
NIM: 2510512028  
File: `scripts/buat_arsip.sh`

1. Tujuan
Membuat arsip backup dengan format `.tar.gz` dari direktori sumber yang valid serta menghasilkan checksum SHA-256 untuk mendukung pemeriksaan integritas arsip.

2. Skenario Positif
- Direktori sumber tersedia dan dapat dibaca.
- Direktori tujuan tersedia dan dapat ditulis.
- Script berhasil membuat arsip `.tar.gz`.
- File checksum `.sha256` berhasil dibuat.
- Isi arsip sesuai dengan direktori sumber.
- Exit status: 0.

3. Skenario Negatif
- Direktori tujuan tidak memiliki izin tulis.
- Script menolak proses pembuatan arsip.
- Pesan kesalahan ditampilkan dan dicatat.
- Exit status: 3.

4. Analisis Sistem Operasi
Proses pengarsipan melibatkan operasi I/O karena sistem membaca file dari direktori sumber dan menulis hasil kompresi ke direktori tujuan.
Permission Linux digunakan untuk membatasi akses terhadap file backup. Arsip menggunakan permission 600 sehingga hanya pemilik file yang memiliki akses baca dan tulis.
Timestamp digunakan sebagai identitas arsip agar hasil backup dapat dibedakan berdasarkan waktu pembuatan.
Checksum SHA-256 digunakan untuk menghasilkan nilai hash yang nantinya dapat diperiksa oleh anggota 3.

5. Kesimpulan
Script `buat_arsip.sh` bertugas membuat arsip backup secara otomatis. Keberhasilan dibuktikan melalui terbentuknya arsip dan checksum, sedangkan penanganan kesalahan dibuktikan melalui penolakan akses ke direktori tujuan yang tidak dapat ditulis.
