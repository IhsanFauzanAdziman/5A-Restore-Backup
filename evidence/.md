## 1. Tujuan Pengujian

Pengujian ini dilakukan untuk memastikan bahwa skrip `buat_arsip.sh` dapat membuat arsip cadangan dengan format `.tar.gz` secara otomatis berdasarkan direktori sumber yang diberikan. Selain itu, skrip harus menghasilkan checksum SHA-256 untuk membantu pemeriksaan integritas arsip serta menangani kondisi kegagalan apabila direktori tujuan tidak dapat ditulis.

## 2. Tugas dan Tanggung Jawab

Sebagai Anggota 2, tanggung jawab yang dikerjakan meliputi:

1. Membuat arsip direktori sumber menggunakan perintah `tar`.
2. Memberikan penamaan arsip berdasarkan tanggal dan waktu pembuatan (timestamp).
3. Menghasilkan checksum SHA-256 menggunakan `sha256sum`.
4. Membatasi izin akses arsip dan file checksum menggunakan permission `600`.
5. Menangani kesalahan ketika proses pembuatan arsip atau checksum gagal.
6. Memastikan proses memberikan exit status sesuai kondisi eksekusi.

## 3. Lingkungan Pengujian

| Komponen | Keterangan |
|---|---|
| Sistem Operasi | Ubuntu Server / Linux |
| Shell | GNU Bash |
| Utilitas arsip | `tar` dan `gzip` |
| Utilitas checksum | `sha256sum` |
| Skrip yang diuji | `scripts/buat_arsip.sh` |

| Direktori tujuan | `output` |

## 4. Implementasi Program

Skrip yang digunakan adalah:

`./scripts/buat_arsip.sh test output`

Program menerima dua parameter, yaitu direktori sumber yang akan dicadangkan dan direktori tujuan tempat arsip disimpan.

Arsip dibuat menggunakan format `.tar.gz` dengan nama berdasarkan timestamp, sedangkan file checksum disimpan menggunakan ekstensi `.sha256`.

## 5. Skenario Pengujian

### 5.1 Pengujian Positif – Pembuatan Arsip Berhasil

**Tujuan:** Memastikan program dapat membuat arsip `.tar.gz` dan checksum SHA-256 dari direktori sumber yang valid.

**Persiapan:**

```bash
mkdir -p tests output
echo "Dokumen pertama" > tests/dokumen1.txt
echo "Dokumen kedua" > tests/dokumen2.txt
chmod +x scripts/buat_arsip.sh
```

**Perintah pengujian:**

```bash
./scripts/buat_arsip.sh tests output
echo $?
ls -lh output/
```

**Pemeriksaan checksum:**

```bash
sha256sum -c "$ARSIP.sha256"
```

**Hasil yang diharapkan:**

- Arsip `.tar.gz` berhasil dibuat.
- File checksum `.sha256` berhasil dibuat.
- Nama arsip memiliki timestamp.
- Exit status menunjukkan `0`.
- Pemeriksaan checksum menampilkan `OK`.

### 5.2 Pengujian Negatif – Direktori Tujuan Tidak Dapat Ditulis

**Tujuan:** Memastikan program menolak pembuatan arsip ketika direktori tujuan tidak memiliki izin tulis.

**Persiapan:**

```bash
mkdir -p readonly
chmod 555 readonly
```

Pengujian dilakukan menggunakan akun pengguna biasa (bukan root) agar pembatasan permission dapat diuji dengan tepat.

**Perintah pengujian:**

```bash
./scripts/buat_arsip.sh dataSumber readonly
echo $?
```

**Hasil yang diharapkan:**

- Program menampilkan pesan kesalahan bahwa direktori tujuan tidak dapat ditulis.
- Proses pembuatan arsip dihentikan.
- Tidak ada arsip baru yang terbentuk di direktori tujuan.
- Exit status menunjukkan `3` sesuai implementasi skrip.

## 6. Analisis Hasil Pengujian

Pengujian positif digunakan untuk mengetahui kemampuan program dalam mengemas direktori sumber menjadi arsip terkompresi. Pembuatan timestamp membantu membedakan arsip berdasarkan waktu pencadangan, sedangkan checksum SHA-256 digunakan sebagai nilai pembanding untuk memeriksa apakah arsip mengalami perubahan.

Pengujian negatif dilakukan dengan memberikan direktori tujuan yang tidak memiliki izin tulis. Melalui validasi permission, program diharapkan dapat menghentikan proses sebelum pembuatan arsip dilakukan. Mekanisme ini membantu mencegah kegagalan proses yang tidak terdeteksi dan memberikan informasi kesalahan kepada pengguna.

## 7. Kesimpulan

Berdasarkan rancangan dan skenario pengujian, skrip `buat_arsip.sh` memiliki fungsi utama untuk membuat arsip cadangan `.tar.gz` dengan timestamp dan menghasilkan checksum SHA-256. Program juga menerapkan pembatasan permission pada file hasil pencadangan serta menangani kondisi kegagalan.

Keberhasilan implementasi dinyatakan setelah pengujian positif dan negatif dijalankan, hasil terminal diperiksa, serta bukti pengujian dilampirkan. Dengan demikian, modul pembuatan arsip dapat digunakan sebagai salah satu tahapan dalam sistem otomasi backup dan pemulihan data Linux.
